# Main Figure 2

Use `continuous.R` to generate simulations and `figure2_result.R` to summarize main Figure 2. The standalone reader selects continuous annotations, n=5000, p=1000, h²=0.05/0.1/0.2, and replicate IDs 1–100. The four plotted methods use result slots 1/3/4/6: Knockoff, AnnoKn, GhostKnockoff (M=1), and AnnoGK (M=1).

From the repository root, after installing the dependencies in [`helpers/legacy/README.md`](../../helpers/legacy/README.md):

```sh
# Example: one replicate. Seed = 1000 * replicate ID.
Rscript reproducibility/run.R simulations/annogk/continuous.R 1
# Run IDs 1 through 100 before summarizing (independent jobs may run in parallel).
Rscript reproducibility/run.R simulations/annogk/figure2_result.R
```

Each generator invocation computes all three p values (300/600/1000), all three heritabilities, and eleven method slots, as in the historical code. The Figure 2 reader uses only p=1000. Generation is computationally intensive; the example invocation alone does not produce all 100 repetitions. Synthetic data are generated by the driver; no external genotype data are needed.

By default, results are written to `reproducibility/outputs/simulations/annogk/`. To summarize existing results, set `paths$annogk_results` in `config.local.R` to their directory. The 300 required filenames are:

```text
heri_final_10_<h>_n_5000_p_1000_<i>.RData
h = 0.05, 0.1, 0.2; i = 1, ..., 100
```

The reader needs `ggplot2` and `dplyr`, and a `result` list with seven finite values in [0,1] for each `power1`–`power11` and `fdr1`–`fdr11`. It rejects missing or invalid results before exporting a plot. Complete valid inputs retain the original arithmetic means. No missing replicate is counted as zero or silently omitted.

Outputs default to `reproducibility/outputs/plots/main/`:

- `AnnoGK_simu_strong_p1000.pdf`: the six-panel Figure 2 plot.
- `AnnoGK_simu_strong_p1000_values.tsv`: the 168 plotted values.
- `AnnoGK_simu_strong_p1000_inputs.tsv`: the 300 input filenames, heritabilities, replicate IDs and MD5 checksums.

The reader saves directly with a generic sans-serif font and Cairo PDF when available, with the standard PDF device as fallback. It does not require Arial or an interactive plotting device. Typography may differ across operating systems.

`result.R` is retained as the historical multi-figure script, including its original defaults and exploratory plotting blocks. Use the standalone reader above for main Figure 2. Supplementary continuous/binary/runtime workflows in the historical script still require their own cleanup and configuration; `binary.R` is not needed for main Figure 2.

Validation: the standalone reader ran on the existing 300 historical results and its 168 exported values matched the previously audited original continuous plotting block at p=1000. That original-block plot's curves matched the final manuscript at PDF coordinate precision after layout alignment. A relocated fixture test checks known means, missing/invalid input rejection, and direct PDF export. Fresh installation and a full rerun of the simulations have not been validated.
